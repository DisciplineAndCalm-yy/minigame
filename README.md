# 迷你游戏厅 · Mini Arcade

一个**多小游戏合集**微信小游戏项目：科幻控制台风格的首页选择游戏，内含五款玩法 + 十一首节奏化程序化背景音乐。
所有图形、音效与音乐均由代码实时生成，**不依赖任何图片 / 音频素材文件**。

同一份游戏核心代码同时运行在**微信小游戏**和**浏览器**两个平台。

## 游戏列表

### 1. 星际合成 · Nova Fusion（科幻画风）

从轨道投放能量球，两个**同等级**能量球相撞即融合为更高等级，从「尘」一路升级到「恒星」。

- **拖动瞄准 · 松手投放**：激光瞄准线 + 全息准星实时指示落点
- **融合进化链**：尘 → 微粒 → 赤岩 → 熔核 → 曜金 → 蓝晶 → 深蓝 → 翠芒 → 环带 → 巨木 → 恒星（11 级）
- **OVERDRIVE 连击**：短时间内连续融合累积倍率（x2、x3…），得分翻倍
- **警戒线**：能量球越过红色扫描虚线并稳定停留即失败，越接近越急促闪烁
- **双恒星彩蛋**：两颗恒星相撞额外获得大量分数
- **视觉**：星云背景、透视网格、能量场容器（含导轨刻度与四角括号）、扫描线、等离子火花、恒星脉动光环

### 2. 小动物消消乐（Q 版可爱画风）

经典「三消 + 堆叠」玩法，还原了羊了个羊的核心乐趣，整体走 Q 版可爱路线。

- **堆叠牌阵**：格子按「靠中心权重更大」随机叠 1~5 层，每堆只能点最上面那张
- **12 种 Q 版小动物**：兔兔 / 喵喵 / 熊熊 / 熊猫 / 猪猪 / 蛙蛙 / 狗狗 / 小鸡 / 狐狸 / 企鹅 / 绵羊 / 猴子
  ——每种都有独立的**轮廓特征**（长耳 / 尖耳 / 圆耳 / 垂耳 / 呆毛 / 眼罩 / 鼓眼 / 大鼻子 / 蓬松羊毛）与专属配色，不靠颜色区分也能一眼认出
- **真实动物叫声**：点击与消除时播放来自 Wikimedia Commons 的**真实录音**（兔 / 猫 / 熊 / 熊猫 / 猪 / 蛙 / 狗 / 鸡 / 狐 / 企鹅 / 绵羊 / 猴），并带随机音高变化；若某条采样加载失败会自动回退到合成音
- **动物会动起来**：
  - 待机**呼吸起伏**（每只相位不同，同屏不同步）
  - 随机**眨眼**（眼睛变成弯弯的闭眼弧线）
  - 偶尔**歪头**、**蹦跳**一下
  - 被压住的小动物会**探头**并冒小气泡
  - 点击时**挤压拉伸**（Q 弹）→ 旋转着**飞进**槽位并留下彩色拖尾 → 落槽**弹跳**
  - 消除时炸出该动物**专属符号**粒子
- **小动物槽位**：点中的小动物走抛物线**飞进**底部槽位，集齐 **3 只同款**即消除
- **消除连锁**：短时间内连续消除累积倍率，分数翻倍，HUD 出现跳动的小火焰倍率指示
- **魔法道具**（3 次）：挥动魔法棒重排棋盘上剩余牌的花色，破解死局
- **失败**：槽位填满且无法消除；**通关**：清空本关全部牌（额外奖励分）+ **彩带雨**
- **主题背景图**：草原 + 会笑的太阳 + 彩虹 + 云朵 + 视差远山 + 摆动草叶 + 飞舞花粉/星点

### 3. 星图点灯 · Lumina（星空梦幻画风）

休闲解压 + 烧脑解谜的「点灯（Lights Out）」玩法：屏幕上是九宫格式的星图，点一颗星会翻转**它自己 + 上下左右四颗相邻星**的亮/灭，目标是把满盘星星**全部点亮**。

- **必定可解**：每关从「全亮」出发，随机按下若干颗星得到开局；因此「把那几颗星再点一遍」就是一条必定的胜利路径，永远不会出现死局
- **烧脑但可推理**：相邻翻转的连锁关系需要推演，步数越紧越考验「先后顺序」；棋盘从 3×3 一路扩到 7×7
- **步数预算**：每关有可用步数（= 正解规模 + 一点点富余），用完仍未点亮即失败，逼你少走废步
- **提示道具**：每关 1~2 次提示，会高亮一颗「当前仍正确的目标星」，卡住时救急
- **解压氛围**：柔和金色辉光、星星呼吸脉动、点击涟漪 + 星尘粒子、漫天星火通关特效
- **沉浸视效**：相邻且点亮的星自动连成**发光星座线**（带流动光点），点亮星带十字星芒，左上角**环形进度圈**实时显示点亮进度 `/ 颗`
- **轻音反馈**：点击 / 点亮 / 通关都有柔和音色，配套舒缓的梦幻 BGM《星图摇篮曲》
- **计分**：基础分 + 节省的步数奖励 + 剩余提示奖励，鼓励「又准又省」通关

### 4. 星驰穿梭 · Star Dash（科幻霓虹 + 动作跑酷）

休闲解压 + 烧脑走位的「动作 + 解谜」跑酷：三车道纵向穿梭，飞船在底部，星岩 / 星屑 / 星门从上方压下。

- **动作手感**：点按左右半屏（或拖拽）即时换道，飞船带挤压缓动、尾焰、拖尾粒子；撞星岩会掉护盾并震屏
- **解谜层**：每通过一道「星门」需要 `跃迁能量 ≥ 门槛`，否则扣护盾——逼你在「贪星屑充能」与「保命走位」之间提前规划；能量攒满可点「跃迁」短时无敌冲刺、撞碎星岩加分
- **必定可走位通过**：星岩按「安全车道随机游走（每行最多移动一格）」生成，因此永远存在一条纯靠走位即可通过的路线；星屑沿安全路径投放，最优解 = 顺路多吃
- **难度**：扇区越高，世界速度越快、行距越密、星岩/双岩封锁越多、星门能量门槛越高
- **特殊波次**（3 区后随机触发，顶部横幅预警）：
  - **陨石雨**：连续 3 行「火焰拖尾陨石」几乎填满非安全道，考验极限走位
  - **黑洞**：连续 4 行生成占据单车道、带旋转吸积盘的奇点；黑洞会对飞船产生**引力拉扯**（需靠换道对抗），碰到即掉护盾；跃迁状态可穿洞并加 50 分
- **护盾**：3 颗，归零结束；最高分 / 最高扇区持久化
- **沉浸视效**：远景带环行星、十字星芒星空、霓虹车道网格、飞船护盾光环与尾焰、陨石火焰拖尾、黑洞吸积盘 + 事件视界、震屏与跃迁闪光、顶部波次横幅

### 5. 星旅者 · Star Wanderer（角色扮演 · 动作战斗 · 多结局）

一段关于「最后的星守」的星海冒险。星核破碎、群星熄灭，你带着微弱的碎片穿越三段旅程，最终直面吞噬一切的「核心吞噬者」。

**完整故事线**（数据驱动节点图，`js/core/quest.js` 的 `NODES`）：

- **序章 · 破碎的星核**：星守苏醒 → 初战虚空游魂 → **抉择①**（救下受伤星民「守光」 vs 取走能量「求力」）
- **第一章**：Boss「堕落哨卫」——第一块星核碎片归位
- **第二章 · 记忆回廊**：坠入破碎记忆 → **抉择②**（拥抱过去 vs 斩断牵绊）→ 记忆残片群战 → Boss「回声之影」
- **终章 · 核心之渊**：直面「核心吞噬者」→ **最终抉择**（献光重创世 / 独揽主宰虚空 / 熄灭归平凡）

**多结局**（4 种，按最终抉择 + 光暗倾向判定，并持久化解锁进度）：

| 结局 | 条件 | 基调 |
| --- | --- | --- |
| 真·光辉创世 | 选「献光」且光暗倾向 ≥ 2（偏光） | TRUE ENDING |
| 光辉守护者 | 选「献光」但倾向偏暗/中立 | GOOD ENDING |
| 虚空主宰 | 选「独揽核心」 | DARK ENDING |
| 平凡旅人 | 选「熄灭核心」 | NORMAL |

**动作战斗**：

- 点按战斗区「斩击」前排敌人，连击（COMBO）越高伤害与暴击越多；满能量放「⚡星爆」对全场造成伤害；每战一次「✚星愈」回血。
- 敌人会「起手预警」（红色扩散环），需在命中前用技能化解压力；战败自动重整旗鼓回到本战起点。
- **升级**：击败敌人获得经验，升级提升攻击/生命并回复部分血量，等级持久化为最高记录。

**UI / Icon / 动效**（全 Canvas 程序化 + 首页 CSS 动画）：

- 角色立绘：兜帽星守剪影 + 眨动眼光 + 脉动星核 + 旋转虚线光环；战斗版带能量满环绕光环。
- **五种怪物各具造型**（不再单调）：`虚空游魂`幽浮水滴 + 拖尾触须 + 单眼、`记忆残片`旋转符文菱形、`堕落哨卫`棱角装甲 + 发光独眼 + 双角 + 环绕碎屑、`回声之影`兜帽镜面人形 + 涟漪重影、`核心吞噬者`旋转破碎环 + 巨眼虹膜扫视 + 放射尖瓣；均带受击白闪抖动、死亡碎片消散、Boss 名称血条与起手预警环。
- **三章主题背景**：序章「余烬」暖橙 + 上升余烬 + 废墟光柱剪影；第二章「深渊」紫蓝 + 悬浮镜面碎片 + 浮光；终章「核心」赤金 + 中央脉动破碎星核 + 核心火花，随章节自动切换。
- 对话**打字机**效果 + 角色名牌 + 章节横幅（发光）；抉择按钮按「光/暗」绿/粉描边。
- 顶部**光暗倾向条**实时指针、可收集结局数显示；结算界面发光星章 + 逐行淡入结语。
- 首页新增「星旅者」卡：发光星剑 + 星核光球 + 星芒脉冲图标。
- **天赋成长**：升级时按光暗倾向获得被动（光→汲光吸血/生命、暗→噬力暴击/攻击、中立→均衡成长）。
- **动态 BGM**：剧情用《星旅史诗》，遭遇战切《遭遇战 · Clash of Stars》，Boss 战切《王座之影 · Shadow of the Throne》。

## 难度梯度

五款游戏都采用**递进式难度**，随进度自动加码：

### 星际合成 · 扇区（SECTOR）系统

每 1200 分进入下一个扇区，最高 30 扇区，难度逐段提升：

| 参数 | 变化 |
| --- | --- |
| 重力 | 每扇区 +6%（第 30 扇约 2.7 倍） |
| 警戒宽限 | 1.7s → 最低 0.9s（反应时间更短） |
| 警戒线下移 | 每扇区下移一点（容错空间更小） |
| 投放花色 | 2 → 3 → 4 级（后期掉落更高级的球） |

最高到达扇区会持久化存档。

### 小动物消消乐 · 关卡系统

清空一关即进入下一关。**槽位恒为 7**，核心规则不变（点最上层 → 集齐 3 只同款消除 → 槽满失败）。难度通过「花色种类 / 堆叠层数 / 顶层同色上限 cap」三者提升，并采用**顶层面板"成对化"**的生成策略：顶层每种动物最多出现 `cap` 张（本版除第 1 关外 `cap=2`），第 3 张往往埋在下一层，因此**无脑连点必败**，必须规划先挖哪一叠、在 7 个槽位内周转。

| 关卡 | 牌数 | 花色数 | 堆叠层数 | 槽位 | 说明 |
| --- | --- | --- | --- | --- | --- |
| 1 | 12 | 3 | 1 | 7 | 熟悉关，单层摆放，3 种动物 |
| 2 | 27 | 6 | 3 | 7 | 起手即需规划，连点必败 |
| 3 | 30 | 7 | 4 | 7 | |
| 4 | 36 | 8 | 4 | 7 | |
| 5 | 39 | 8 | 5 | 7 | 堆叠 +1 层 |
| 6 | 42 | 9 | 5 | 7 | |
| 7 | 45 | 9 | 5 | 7 | |
| 8 | 48 | 10 | 5 | 7 | |
| 9 | 51 | 10 | 6 | 7 | 堆叠 +1 层 |
| 10 | 54 | 11 | 6 | 7 | |
| 11+ | +6/关，花色逐级增至 12，层数到 6 | | | 7 | 无限加难 |

实测（浏览器内用启发式求解器各跑上百局统计的胜率）——「随便点」vs「会规划」，并**不含 3 次魔法重排道具**（道具会进一步降低实际难度）：

| 关卡 | 乱点胜率 | 会玩胜率 |
| --- | --- | --- |
| 1 | 100% | 100% |
| 2 | 0% | ~57% |
| 5 | 0% | ~24% |
| 7 | 0% | ~8% |
| 10 | 0% | ~1% |
| 12+ | 0% | ≤1% |

旧版本乱点几乎必过（≈100%）；上一版第 2 关会玩胜率约 89%。本版**乱点必败**，会玩也要认真权衡，且关卡越高越吃规划与道具运用。最高关卡会持久化存档。

### 星图点灯 · 关卡系统

每关棋盘边长与「生成步数 k、可用步数富余 slack、提示次数」共同决定难度。因为**每关都从全亮态反向打乱而来，所以必定可解**（把打乱的星再点一遍即可）。

| 关卡 | 棋盘 | 生成步数 k | 步数预算 | 提示 |
| --- | --- | --- | --- | --- |
| 1 | 3×3 | 3 | k+4 | 2 |
| 2 | 3×3 | 4 | k+4 | 2 |
| 3 | 4×4 | 6 | k+4 | 2 |
| 4 | 4×4 | 8 | k+3 | 2 |
| 5 | 5×5 | 10 | k+3 | 2 |
| 6 | 5×5 | 13 | k+2 | 2 |
| 7 | 6×6 | 16 | k+2 | 1 |
| 8 | 6×6 | 20 | k+2 | 1 |
| 9+ | 7×7 | 逐关加大 | k+1~2 | 1 |

难度来源：棋盘越大、翻转连锁越复杂；`slack`（预算 - 正解步数）越小越不容失误。乱点几乎必败，需要「先想清楚按哪几颗、按什么顺序」才能通关。


## 背景音乐

内置 **11 首**由 WebAudio 振荡器 + 噪声合成的**节奏化** BGM。进入每个场景自动播放该场景的主曲目；页脚右下角 **♫ 按钮**可在场景内的备选曲目间切换：

| --- | --- | --- | --- |
| `menu` 弧光圆舞曲 | 舒缓 Lo-fi 律动 | 96 | 首页（主） |
| `victory` 星耀庆典 | 明亮欢快 | 116 | 首页（备） |
| `cute` 咩咩小舞曲 | 跳跃大调五声 | 124 | 小动物消消乐（主） |
| `cozy` 暖阳小品 | 慵懒放松 | 104 | 小动物消消乐（备） |

| `puzzle` 星图摇篮曲 | 舒缓梦幻氛围 | 84 | 星图点灯（主） |
| `action` 疾速星驰 | 疾速电子动作 | 148 | 星驰穿梭（主） |

| `boss` 王座之影 | 压迫式史诗 | 150 | 星旅者（Boss 战） |

场景→曲目映射见 `js/core/app.js` 的 `tracksByScene`；`App.nextTrack()` 轮换当前场景曲目。

每首使用 16 分音符步进器，包含：底鼓（正弦扫频）、军鼓（带通噪声）、踩镲（高通噪声）、贝斯、和弦铺底、主旋律琶音；`cute`/`cozy`/`victory` 额外带 swing 摇摆律动。

**节奏递增**：音频引擎支持 `setIntensity(0~1)` 紧凑度参数，同时影响**速度**（最高 +22%）与**鼓点密度**（踩镲加密、附加底鼓、高八度点缀）：

- 首页固定 0.12（休闲）
- 小动物消消乐：第 1 关 0.12，第 2 关起 0.52 并随关卡 +0.08（上限 0.92）
- 星际合成：随扇区推进 0.35 → 0.95

音效（投放 / 融合 / 消除 / 升级 / 恒星 / 胜利 / 失败）同样为程序化合成；小动物则使用**真实动物录音**（见下方素材来源）。页脚播放器显示当前曲目并提供一键静音。

### 场景管理器

`js/core/app.js` 负责：

- 持有 `home / merge / sheep / lumina / dash / quest` 六个场景，统一 `resize / update / render / pointerDown / pointerMove / pointerUp` 接口
- 场景通过 `scene.nav.goto(name)` / `scene.nav.back()` 跳转
- 切换场景时自动调用 `audio.playTrack()` 切歌（每个场景带主/备曲目库，可轮换），并通过 `onSceneChange` 回调同步页脚播放器
- 切换场景时播放**扫光 + 黑场渐隐**过渡动画
- 各游戏均有「‹ 首页」按钮，结算面板提供「返回首页」

## 运行方式

### 浏览器预览

使用了普通 `<script>`（非 ES Module），可直接双击 `index.html` 打开。
若浏览器对本地文件有访问限制，建议用任意静态服务器启动（示例）：

```bash
# 有 Node 时
npx serve .
# 有 Python 时
python -m http.server 8765
```

然后访问 `http://localhost:8765/`。

### 微信小游戏

用「微信开发者工具」打开本目录，编译后即可在模拟器 / 真机预览。

## 实现要点

- **物理**（星际合成）：固定步长（1/120s）+ 多次迭代的位置修正，圆-圆、圆-墙碰撞稳定不抖动
- **牌阵生成**（小动物消消乐）：格子按「靠中心权重更大」随机堆叠，牌数保证为 3 的倍数；花色按三张一组分配（保证必定可解），并做**顶层成对化 + 同格上下不同色**处理：顶层每种最多 `cap` 张，第 3 张优先埋在浅层，使「无脑连点」会迅速塞满 7 个槽位而失败，必须规划挖取顺序
- **点灯可解性**（星图点灯）：每关用「从全亮态反向按下 k 颗随机星」生成，所以必然可解；剩余正解 = 生成集 XOR 已按集合，提示功能据此高亮一颗当前正确的星，无需外部求解器
- **渲染**：全部 Canvas 程序化绘制——能量球用径向渐变 + 能量纹路 + 辉光描边 + 待机脉动；小动物用渐变牌面 + 独立轮廓特征（耳朵/呆毛/眼罩）+ 眼睛高光 + 腮红 + 呼吸/眨眼动画
- **性能优化（消消乐后期卡顿）**：把每种动物牌**离屏烘焙成精灵**（睁眼/闭眼两版，一次性生成，尺寸变化时重建），每帧只 `drawImage`，彻底去掉逐帧 `createLinearGradient`/`clip` 的重活；顶层判定由 O(n²) 的 `_isTop` 改为**每帧单次遍历**求顶层；高分关（80+ 张）实测渲染约 0.3ms/帧，中端手机也能稳定 60fps
- **动画**：每只动物有独立相位，实现非同步呼吸、眨眼、歪头、蹦跳；点击触发挤压拉伸 → 旋转飞行 + 彩色拖尾 → 落槽弹跳；场景层加入太阳光芒、视差远山、摆动的草、漂浮符号等氛围元素
- **动画**：牌面弹性入场（easeOutBack）、消除粒子爆散、飞入槽位的抛物线轨迹、结算面板旋转星装饰
- **音频**：WebAudio 振荡器 + 噪声缓冲实时合成 BGM 与音效，零素材文件
- **存档**：各游戏最高分 / 最高关卡 / 最高扇区持久化到 `localStorage`（网页）或 `wx.setStorageSync`（微信），键名 `nova.best` / `nova.sector` / `animal.best` / `animal.level` / `lumina.best` / `lumina.level` / `dash.best` / `dash.sector` / `quest.best` / `quest.endings` / `quest.seen`
- **走位公平性**（星驰穿梭）：星岩沿「安全车道随机游走」生成（每行最多移动一格），并记录隐形安全标记；实测「完美跟随安全道」的 AI 可稳定通过 100+ 行，证明每关都存在纯走位解，难度只来自速度与预判
- **特殊波次**（星驰穿梭）：每 6~10 行且 3 区后随机触发陨石雨 / 黑洞；黑洞波次用「避开洞车道的安全道游走」生成、黑洞提供的引力拉扯在 update 中以偏移速度叠加到飞船横移，既强化压迫感又不破坏可走位性（跃迁可穿洞）
- **页面级沉浸视效**（网页外壳）：在游戏画布上叠加 `.frame::after` 扫描线 + 暗角 + 内阴影，及 `.glare` 周期性斜向微光扫过（纯 CSS，`pointer-events:none` 不挡点击）；配合卡片按压、场景切换扫光/渐隐、首页浮游装饰
- **RPG 剧情与多结局**（星旅者）：`NODES` 数据驱动节点图（story / choice / battle 三类节点），抉择累加光暗倾向；结局按「最终抉择 + 倾向阈值」判定，用 `quest.seen` 位掩码持久化已解锁结局；战斗为实时点按 + 技能 + 起手预警 + 升级成长，战败回本战检查点
- **RPG 怪物与场景美术**（星旅者）：五种怪物各自独立 Canvas 绘制函数（`_drawWisp/_drawShard/_drawSentinel/_drawEcho/_drawDevourer`），含呼吸/旋转/受击抖动/死亡碎片消散；背景按 `NODE_ACT` 切三章主题（余烬/深渊/核心），含章节专属远景（废墟剪影/镜面碎片/脉动星核）与时间驱动的余烬、浮光、火花粒子；BGM 随节点在 adventure/battle/boss 间自动切换
